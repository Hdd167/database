## 2. UML-диаграмма классов

```mermaid
classDiagram
    class Пользователь {
        -int id_пользователя
        -string фио
        -string email
        -string телефон

        -string статус
        +зарегистрироваться()
        +добавитьКарту()
        +начатьПоездку(самокат)
        +завершитьПоездку()
        +оставитьОтзыв(самокат, оценка, текст)
    }
    class ПлатежнаяКарта {
        -int id_карты
        -string маскированный_номер
        -string платежная_система
        -date срок_действия
        -bool основная
        +сделатьОсновной()
    }
    class Станция {
        -int id_станции
        -string название
        -string адрес
        -string координаты
        -int вместимость
        -float рейтинг
        +свободныеСамокаты()
        +обновитьРейтинг()
    }
    class Зона {
        -int id_зоны
        -string название
        -string описание
    }
    class Самокат {
        -int id_самоката
        -string серийный_номер
        -string модель
        -int уровень_заряда
        -string статус
        +заблокировать()
        +разблокировать()
        +обновитьЗаряд(уровень)
        +сменитьСтатус(статус)
    }
    class Тариф {
        -int id_тарифа
        -string название

        -decimal цена_разблокировки

    class Платеж {

    }

        -string текст
        -date дата

        +удалить()
    }

        -string телефон
        -string номер_смены
        -string статус

        +завершитьЗадачу()
    }
    class Обслуживание {
        -int id_обслуживания
        -date дата
        -string тип
        -string статус
        +начать()
        +завершить()
    }
```

## 4. Диаграмма последовательностей «Начало поездки»

```mermaid
sequenceDiagram
    actor Пользователь
    participant Приложение
    participant Система
    participant Самокат
    participant ПлатежныйШлюз
    Пользователь->>Приложение: Выбирает самокат на карте
    Приложение->>Система: Запрос доступности самоката
    Система->>Система: Проверка статуса, заряда,<br/>активной поездки
    Система-->>Приложение: Самокат доступен
    Приложение->>Система: Создать поездку
    Система->>Система: Создать поездку (статус = активна)
    Система->>ПлатежныйШлюз: Авторизация суммы разблокировки
    ПлатежныйШлюз-->>Система: Успех
    Система->>Самокат: Разблокировать
    Самокат-->>Система: Разблокирован
    Система->>Система: Статус самоката = арендован
    Система-->>Приложение: Поездка создана
    Приложение-->>Пользователь: Поездка начата
```

## 5. Диаграмма последовательностей «Завершение поездки и оплата»

```mermaid
sequenceDiagram
    actor Пользователь
    participant Приложение
    participant Система
    participant Самокат
    participant ПлатежныйШлюз
    Пользователь->>Приложение: Завершить поездку
    Приложение->>Система: Запрос завершения поездки
    Система->>Самокат: Заблокировать
    Самокат-->>Система: Заблокирован и координаты
    Система->>Система: Дата окончания, конечная станция
    Система->>Система: Рассчитать итоговую сумму
    Система->>ПлатежныйШлюз: Списать сумму
    ПлатежныйШлюз-->>Система: Успех
    Система->>Система: Создать платёж (успешный)
    Система->>Система: Статус поездки = завершена
    Система-->>Приложение: Чек и итоговая сумма
    Приложение-->>Пользователь: Поездка завершена
```

```mermaid
sequenceDiagram

    БазаДанных-->>Система: Успех
    Система->>Система: Пересчитать рейтинг самоката
    Система-->>Приложение: Отзыв сохранён
    Приложение-->>Пользователь: Спасибо за отзыв
```

## 7. Диаграмма последовательностей «Обслуживание самоката механиком»

```mermaid
sequenceDiagram
    actor Администратор
    actor Механик
    participant Система
    participant Самокат
    Администратор->>Система: Создать обслуживание
    Система->>Система: Статус обслуживания = новая
    Механик->>Система: Взять задачу
    Система->>Механик: Назначить обслуживание
    Система->>Система: Статус = в работе
    Механик->>Самокат: Физическое обслуживание
    Механик->>Система: Завершить задачу
    Система->>Система: Статус = завершена
    Система->>Самокат: Обновить заряд и статус
    Система-->>Механик: Задача закрыта
```
